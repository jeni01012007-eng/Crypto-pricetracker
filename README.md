Cryptocurrency Price Tracker

A real-time cryptocurrency price tracking web application that collects cryptocurrency market data from CoinMarketCap and displays it through an interactive web dashboard.

## 🚀 Features

- 📊 Real-time cryptocurrency price tracking
- 🏆 Cryptocurrency ranking
- 💰 Current cryptocurrency prices
- 📈 24-hour price change monitoring
- 💵 Market capitalization
- 📦 Trading volume
- 🌐 CoinMarketCap-based data collection
- 🤖 Automated data scraping using Selenium
- 🖥️ Flask-based web dashboard
- 📁 CSV-based data storage
- 🌙 Clean and responsive dashboard interface

## 🛠️ Technologies Used

## 🎯 Project Objective

The Cryptocurrency Price Tracker is developed to provide an easy-to-use platform for monitoring cryptocurrency market information in one place.

The application collects cryptocurrency data, processes the information, stores it in CSV format, and presents the results through a Flask-based web dashboard.

## 🔍 Key Functionalities

The system provides cryptocurrency rankings, current prices, 24-hour price changes, market capitalization, and trading volume.

Selenium is used to collect cryptocurrency information from CoinMarketCap, while Python and Pandas are used for data processing and storage. Flask is used to serve the web dashboard.
